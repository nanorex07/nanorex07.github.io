PyNeat is an implementation of the NEAT algorithm, which evolves neural networks through an evolutionary process. 
This project explores neuroevolution by training agents to solve complex tasks using evolving topologies.

### To use this code for your project
- Import gene and genome from src directory
-  Write genetic algorithm for your projects 

### To run flappy bird example 
- Install PyGame
- Run main.py file from examples/flappy-bird directory
