Denarii is a feature-rich expense tracker designed to help users manage their finances effectively. 
It includes categorization, visual reports, and a user-friendly interface for tracking daily spending.
Without any authentication it runs locally on your device.

## Dependencies

- Python 3.6+ With Tcl/Tk
- Matpltlib
- Pillow

## How to run ?

For Windows
```sh
pip install -r requirements.txt
python main.py
```
